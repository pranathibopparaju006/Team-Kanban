# Final Project Scope

TeamKanban is a collaborative project operations platform. It is intentionally distinct from an AI evidence-analysis system: its purpose is to coordinate work, people, workflows, deadlines and progress.

Major-project modules planned for the final iteration:
- Authentication and RBAC
- Organization/project management
- Configurable workflow states
- Tasks/subtasks
- Team assignment
- Comments
- Notifications
- Audit/activity history
- Sprint management
- Analytics and reporting
- Real-time collaboration
- PHP reporting/export integration
